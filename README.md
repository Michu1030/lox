Both implementations of the Lox programming language taken from the book "Crafting Interpreters", one in Java and the other in C. The java version is a tree-walk interpreter, which basically means code is executed directly from AST. Simple to implement but quite slow for more serious use cases. The C version has it's own VM and bytecode that it executes so it's also a compiler in some sense but it skips the AST step by producing the bytecode directly from source which has a few benefits like being short enough to cover in a book but it may be harder to implement certain optimizations directly in bytecode so it's not that common. Most of the code is exactly as it is in the book.
